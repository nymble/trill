# Trillium brand kit

The brand kit for Trillium, an Ambient Lab project. It uses the Stage palette.

- **`BRAND.md`**: the full guide, covering names, marks, color and contrast, type, UI and key visuals.
- **`AGENTS.md`**: a one-page summary for AI agents working in this repo.
- **`tokens/`**: colors and fonts as JSON (W3C design tokens), CSS variables and SwiftUI.
- **`icons/`**: the Rhodonea (primary) and Field lines (secondary) marks as SVG and PNG.
- **`apple/`**: ready-to-use Xcode app icon sets for macOS and iOS, plus `Trillium.icns`.
- **`wordmark/`**: the outlined wordmark and five lockups.
- **`visuals/`**: the Light trails key visual, cropped for web, social, launch screen and release notes.
- **`ui-icons/`**: twelve 24 px in-app icons that take their color from the surrounding text (`currentColor`).

Fonts aren't bundled. Outfit, Inter and IBM Plex Mono are open source (SIL OFL 1.1) and available on Google Fonts. The wordmark letters are outlines made from Outfit, which the OFL permits.
